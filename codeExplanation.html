02 — HTML

HTML Structure

Every section of the page, explained.

The <head> Tag hidden settings

The <head> is never visible on the page. It holds the page title (shown in browser tab), links to Google Fonts, and the <style> tag containing all CSS. Think of it as the instruction manual for the browser.

head section — silver-jewellery.html
<head>
  <!-- Page title shown in browser tab -->
  <title>Silver & Soul - Jewellery Collection</title>

  <!-- Load beautiful fonts from Google (needs internet) -->
  <link href="https://fonts.googleapis.com/css2?family=Playfair+Display..." />

  <!-- All our CSS styling lives inside this tag -->
  <style>
    ... all CSS code ...
  </style>
</head>

03 — CSS

CSS — Making it Beautiful

Colors, fonts, layouts, and animations.

CSS Variables :root

Instead of typing the same color code 50 times, we store colors in one place called :root. Think of it like a dictionary. We name a color once, then use that name everywhere. If we want to change the whole page's silver tone, we only change ONE line!

color variables — CSS
:root {
  /* Name the color once, use it everywhere */
  --silver:  #C0C0C0;   /* classic silver */
  --dark:    #1a1a2e;   /* dark navy */
  --accent:  #a8c5da;   /* soft blue */
  --gold:    #f0e6d3;   /* warm white text */
}

/* Now use it anywhere like this: */
.logo {
  color: var(--silver);  /* uses the silver value */
}

Flexbox display: flex

Flexbox is a CSS layout tool that places items side by side in a row (or column). It's used in the navigation bar to place the logo on the left and links on the right automatically.

flexbox — navigation bar CSS
nav {
  display:          flex;             /* place items in a row */
  justify-content:  space-between;   /* logo left, links right */
  align-items:      center;          /* vertically center them */
  padding:          18px 60px;       /* spacing inside nav */
  position:         sticky;          /* sticks to top on scroll */
  top:              0;               /* stick at the very top */
}

CSS Grid display: grid

Grid creates rows and columns like a table. The 6 jewellery cards use a 3-column grid. Write grid-template-columns: repeat(3, 1fr) — this means "make 3 equal columns". Simple!

grid layout — cards section CSS
.cards-grid {
  display:                 grid;
  grid-template-columns:  repeat(3, 1fr); /* 3 equal columns */
  gap:                     30px;           /* space between cards */
  max-width:               1100px;
  margin:                  0 auto;         /* center on page */
}

Hover + Transition animations

:hover means "apply this style when the mouse is on top of it". transition controls how smoothly the change happens. Without transition it's instant. With transition: 0.3s, it glides smoothly.

hover animation — card CSS
/* Normal state */
.card {
  transition: transform 0.3s;   /* smooth over 0.3 seconds */
}

/* When mouse hovers over the card */
.card:hover {
  transform: translateY(-8px); /* lift card 8px upward */
}

/* Image zooms in smoothly when card is hovered */
.card:hover .card-image img {
  transform: scale(1.08);      /* zoom in 8% */
}

Responsive Design @media

The @media rule detects the screen size. On mobile screens (smaller than 768px), we switch the 3-column grid to 1 column so cards don't squish together. This is how websites adapt to phones!

mobile responsive — @media CSS
/* This applies ONLY when screen is less than 768px wide */
@media (max-width: 768px) {

  .cards-grid {
    grid-template-columns: 1fr;  /* only 1 column on mobile */
  }

  .features-grid {
    grid-template-columns: 1fr 1fr; /* 2 columns on mobile */
  }

}
Key CSS Concept: Every HTML element with a class="name" attribute is styled by .name { } in the CSS. The dot (.) before the name means "class". That connection between HTML and CSS is the heart of web design.

04 — JAVASCRIPT

JavaScript — Interactivity

Three features that bring the page to life.

  • 01

    Scroll Fade-In Animation

    When you scroll down the page, each section fades in smoothly. This uses IntersectionObserver — a built-in browser tool that watches when elements appear on screen. When an element enters the screen, JavaScript adds the class "visible" which triggers the CSS fade animation.

  • 02

    Smooth Scroll Navigation

    Clicking a nav link (like "Collections") doesn't jump directly — it glides smoothly to that section. We use scrollIntoView({ behavior: 'smooth' }). We also call e.preventDefault() to stop the default instant-jump behaviour first.

  • 03

    Subscribe Button Logic

    When the user clicks Subscribe, JavaScript checks if the email box is empty. If it has text, it shows a thank-you message and clears the box. If it's empty, the input border briefly turns blue to alert the user. This is basic form validation.

scroll fade-in — JavaScript
// Step 1: Find all elements with class "fade-in"
const fadeElements = document.querySelectorAll('.fade-in');

// Step 2: Create an observer that watches when they appear on screen
const observer = new IntersectionObserver(function(entries) {
  entries.forEach(function(entry) {

    // Step 3: If the element is now on screen...
    if (entry.isIntersecting) {
      // ...add "visible" class which triggers CSS animation
      entry.target.classList.add('visible');
    }
  });
}, { threshold: 0.15 }); // trigger when 15% is visible

// Step 4: Tell the observer to watch every fade-in element
fadeElements.forEach(function(el) {
  observer.observe(el);
});
subscribe button — JavaScript
function subscribe() {
  // Find the input box and success message by their id
  const input = document.getElementById('emailInput');
  const msg   = document.getElementById('successMsg');

  // Check if the email box has something typed in it
  if (input.value.trim() !== '') {
    msg.style.display = 'block';  // show thank-you message
    input.value = '';            // clear the input box
  } else {
    // If empty: flash the border blue to alert the user
    input.style.border = '1px solid #a8c5da';
    setTimeout(function() {
      input.style.border = '1px solid rgba(192,192,192,0.3)';
    }, 1500); // reset after 1.5 seconds
  }
}

05 — IMAGES

How Images Work

Unsplash URLs — free, beautiful, no download needed.

The <img> Tag HTML

Images are added with the <img> tag. The src attribute holds the image URL (address). The alt attribute provides a description for screen readers and when the image fails to load. All images come from Unsplash.com — a free high-quality photo platform.

image tag — HTML
<!-- src = the web address of the image -->
<!-- alt = text description (for accessibility) -->
<img
  src = "https://images.unsplash.com/photo-123?w=600"
  alt = "Moonbeam Silver Pendant"
/>

/* In CSS we use object-fit to control how the image fills its box */
.card-image img {
  width:       100%;          /* fill full width of card */
  height:      100%;          /* fill full height */
  object-fit:  cover;         /* crop to fill, no stretching */
}
🔗

URL Images (Unsplash)

We link directly to Unsplash's servers using a URL. No image files needed on our computer. Just paste the link in the src attribute.

📐

object-fit: cover

This CSS property makes the image fill its container perfectly without distortion — like how a background photo fills a TV screen.
